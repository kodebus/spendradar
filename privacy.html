Privacy Policy

Effective date: July 28, 2026  ·  Spend Radar

Overview

Everything you enter into Spend Radar — your spending limit, cycle day, and transactions — is stored only in your own browser. Nothing is sent to a server, except when you choose to use the screenshot-import feature, which sends the image you paste to Anthropic's API to read the transaction rows.

This Privacy Policy describes how Spend Radar (the "app"), developed by Japps.ai, handles information when you use it.

Information We Collect / Do Not Collect

Spend Radar has no backend server and no user accounts. We do not collect, receive, or have access to any of the following:

  • Your cardholder name, spending limit, or cycle-reset day
  • Any transactions you import, whether by CSV, pasted text, or screenshot
  • Any optional Anthropic API key you choose to enter in Settings

All of this data lives entirely in your browser, on your device.

Local Storage / Backend Storage

Spend Radar uses your browser's local storage to save your settings and transaction history between visits. This data never leaves your device and is never transmitted to Japps.ai or any server we operate. Clearing your browser data, or using the app's own "Clear all" control, will permanently delete it. There is no backend database and no cloud sync.

Third-Party Services

The optional "paste a screenshot" import feature sends the pasted image directly from your browser to Anthropic's API to extract transaction rows as text. This is the only feature that transmits any data outside your browser, and it only runs when you actively use it. If you use CSV upload or paste-text import instead, no data ever leaves your device. If you choose to enter your own Anthropic API key in Settings so the feature works once this app is hosted on its own site, that key is stored only in your browser's local storage and is sent solely to Anthropic's API, never to Japps.ai.

Children's Privacy

Spend Radar is not directed at children under the age of 13, and we do not knowingly collect any information from minors.

Changes to This Policy

If this Privacy Policy is updated, the new version will be posted at this URL with a revised effective date. Continued use after any changes constitutes acceptance of the updated policy.
